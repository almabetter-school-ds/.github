### Make the most of a repository

- **Start with its README** for the project's goal, setup steps, examples, and known limitations.
- **Learn by experimenting** with code and ideas in your own branch or fork, where reuse is permitted.
- **Check the license** before using or redistributing code; individual repositories may have different terms.
- **Contribute thoughtfully** by following the issue, pull request, and contribution guidance in each repository.
